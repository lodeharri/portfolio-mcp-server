Try the MCP server

Six tools that expose Harrison Rodriguez's portfolio — project metadata, semantic code search, architecture summaries, README digest, architecture diagrams, and a free-form agent. Each card below calls one tool directly; results render inline.

list_projects

List every project declared in the manifest with its current index size.

search_code

Hybrid lexical/semantic search over the pre-indexed code chunks.

explain_architecture

Summarize a project's architecture from its ADR (LLM, max 350 tokens).

summarize_readme

Recruiter one-paragraph summary of a declared README (LLM, max 200 tokens).

get_architecture_diagram

Inline SVG architecture diagram from the manifest-declared SVG file.

ask_portfolio streaming

Free-form question routed through a LangChain ReAct agent that calls the other five tools as needed. The agent streams tokens via SSE in the dedicated Chat tab.
